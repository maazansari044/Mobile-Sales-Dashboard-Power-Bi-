#📱Mobile Sales Power BI Dashboard

## Project Overview

This project is an interactive Mobile Sales Dashboard created using Microsoft Power BI.

The dashboard analyzes mobile sales data from 2021 to 2024 and provides insights into sales performance, transactions, quantity sold, average price, brands, mobile models, cities, payment methods, ratings, and monthly trends.

## Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX
- Data Visualization

## Dashboard Features

### 1. Sales Dashboard
- Total Sales
- Total Transactions
- Total Quantity
- Average Price
- Monthly Sales Analysis
- Quarterly Sales Analysis
- Yearly Sales Analysis
- Same Period Last Year Comparison

### 2. MTD Report
- Month-to-Date Sales Analysis
- Monthly Sales Trend
- Interactive Month Selection

### 3. Detailed Sales Analysis
- Total Sales by City
- Sales by Mobile Model
- Sales by Brand
- Quantity by Month
- Payment Method Analysis
- Rating Status Analysis
- Sales by Day Name

- ## Key Insights

- Compared current sales with the same period of the previous year.
- Analyzed monthly, quarterly and yearly sales trends.
- Identified top-performing cities, brands and mobile models.
- Analyzed different payment methods used by customers.
- Studied customer rating categories.
- Created interactive filters for detailed analysis.

## Objective

The objective of this project is to transform raw mobile sales data into an interactive business intelligence dashboard that helps understand sales performance and customer purchasing patterns.
